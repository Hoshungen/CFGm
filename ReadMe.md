## Notlar
* The Complex: Expedition oyununda 16:9'da görünen siyah barları kaldırmak için **Nvidia Control Panel/AMD** ile özel çözünürlük oluşturmanız gerekmektedir yoksa görüntü 1440x1080'de oynanınca inanılmaz bulanık görünüyor. Bu nedenle 2880x2160 veya 2160x1620 çözünürlüklerinde oynanmasını tavsiye ediyorum ama oyununuz bu çözünürlüklerde kasabileceğinden ayar düşürmeniz gerekebilir. (Oyunu çok başarılı buldum ancak 16:9'da bu siyah barların görünmesini hiç sevmedim. İnsanlara yardımcı olabilmek amacıyla Steam Rehberde sayfa oluşturmaya çalıştığımda hata aldığımdan buraya koymaya karar verdim. -- Eklediğim ekran görüntüsü 2880x2160 çözünürlüğünde alınmıştır, boyutu düşürmek için bu şekilde ekledim)
